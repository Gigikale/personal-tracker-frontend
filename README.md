# Personal Tracker Frontend

This is the frontend application for the **Personal Tracker** project, developed using **Vue.js**. It provides users with an interactive and responsive interface to manage personal expenses, view summaries, and gain financial insights.

## 🎯 Purpose

To help users efficiently track and manage their daily expenses and budgeting goals using a simple and intuitive interface.

## 🚀 Technologies Used

- **Axios** for HTTP requests
- **CSS** for styling
- **Vite** for fast build and development
- **Chart.js** for data visualizations

## 🧩 Features

- Add, edit, and delete expenses
- Filter expenses by category and month
- View spending summaries with charts
- Responsive design for mobile and desktop
- Dark mode toggle
